Task3-C#.........(11/10)

part 1:
# 🎲 Guessing Game Application (C#)
## 📌 Features

* **Random Generation:** Generates a target number between 50 and 75.
* **Interactive Hints:** Guides the user with "Try a higher number" or "Try a lower number".
* **Attempt Tracker & Scoring:**
  * **1st attempt:** 10 points
  * **2nd attempt:** 7 points
  * **3rd attempt:** 5 points
  * **4+ attempts:** 0 points
* **Loop Control:** Uses a `while` loop until the correct number is guessed.




part 2: 
# 🏫 School System Application (C#)
## 📌 Features & Concepts

* **Arrays & Loops:**
  * Displays student names using a `for` loop.
  * Displays student grades using a `foreach` loop.
* **Linear Search:** Searches for a student by name using a `while` loop with a `break` statement.
* **Grade Evaluation:** Categorizes student marks into performance grades using conditional `if / else` logic:
  * `90 - 100`: Excellent
  * `80 - 89`: Very Good
  * `70 - 79`: Good
  * `60 - 69`: Pass
  * `Below 60`: Fail
* **Interactive Menu:** Menu driven by a `do-while` loop and `switch` statement.

# 🏫 School System - C# OOP Basics

A simple C# console application demonstrating the core fundamentals of **Object-Oriented Programming (OOP)**, including Classes, Objects, Methods, and Constructors.

---

## 📌 Features & Implementation

* **`Student` Class:** Encapsulates properties for `Name`, `Age`, and `Grade`.
* **Parameterized Constructor:** Initializes object properties upon instantiation.
* **`DisplayInfo()` Method:** Prints formatted student details to the console.
* **Multiple Objects:** Instantiates and manages multiple student instances inside `Main()`.
